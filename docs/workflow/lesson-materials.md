# 章节教学材料

学某一章时，按本文生成材料。学什么以该章 `docs/specs/chNN-*.spec.md` 为准，代码写法以 `docs/standards/` 为准。spec 只圈范围，不代替讲解。

## 动笔之前

1. 读 `docs/standards/ai-coding.md`、该章 spec、本文。
2. 把 spec 的状态改成 `学习中`。
3. 只覆盖「以后生成示例时要覆盖的点」。「不展开」的内容停在那一界。示例为了能跑而必须碰到后章概念时，用最小用法，并在脚本注释里标明「第 N 章再展开」。

## 一章要留下的材料

目录用 spec 里的「示例目录」，例如 `lessons/ch06-input/`。学到该章再创建，不要提前建空目录。

```
lessons/ch06-input/
  guide.md          给人读的讲解
  README.md         怎么运行、跑完应看到什么
  scenes/           可运行场景，一个关注点一个场景
  scripts/          这些场景的脚本
```

本章专用的图、声音放在该目录下，例如 `lessons/ch11-tilemap/tiles/`。只有正式游戏会反复用到的资源才放 `assets/`。中文字体仍放 `assets/fonts/`。

### guide.md

用简体中文写给正在学的人。按编号学到这里，默认前面的章已经看过。固定这几节，没有的内容就写「本章没有」：

1. 这一章解决什么问题。用一两段话说清，不罗列 API。
2. 先看哪棵场景树。写出根节点、关键子节点，以及谁是实例化进来的。
3. 代码在做什么。按脚本职责说明，指出该看哪个函数。不把代码再翻译一遍。
4. 建议改一处。只改一个数字、条件或检查器里的值，并写明输出或画面会怎样变。
5. 自测。用该章 spec 里的自测题，写清怎样算通过。
6. 本章停在哪里。把 spec 的「不展开」收成几句，避免顺着示例做到后面的章。

### README.md

操作说明放这里，不要塞进脚本注释。每章都要写：

- 对应哪一份 spec
- 每个场景演示哪一个关注点
- 运行命令。在仓库根目录执行，场景路径用 `res://`：

```
godot --path . res://lessons/ch06-input/scenes/move.tscn
```

- 只核对输出、不需要窗口时，加上 `--headless --quit-after 1`
- 运行后窗口里应看到什么，终端里应打印什么
- 场景树里哪些节点是必须的
- 若改了 `project.godot`，逐项写明新增的动作名、按键或 Autoload 名

### 场景和脚本

- 一个关注点一个场景。spec 里有两条覆盖点，就做两个场景。
- 脚本遵守 `docs/standards/`：Tab、静态类型、文件头三行注释、失败时 `push_error`。学习示例默认不写 `class_name`。
- 画面上需要汉字时使用 `assets/fonts/`。还没有字体文件时，画面用英文或数字，中文放在 `print` 和 `guide.md`。

## 怎样跑给学员看

生成后由助手在终端运行，不要求学员先打开编辑器。

- 关注点在输出文字上：用无界面命令跑完，把实际打印写进 README，并和预期对照。
- 关注点在画面上：再启动一次不带 `--headless` 的命令，窗口出现在学员机器上。
- 需要按键才看得全的示例，在 `guide.md` 写清按哪些键。窗口打开后的操作由学员完成。

编辑器里打开该场景再按 F6，和上面的命令是同一件事。不要把课程场景写成 `project.godot` 的 `run/main_scene`，也不要改 `scenes/main/`。

## 改 project.godot 的界限

输入动作和 Autoload 只能写在项目文件里，课程示例允许追加，不允许改主场景。

- 动作名带章节前缀：`ch06_left`、`ch06_accept`。脚本里只用动作名，不写死按键码。
- Autoload 的名字带章节前缀，脚本放在该章 `scripts/` 下。
- 只追加本章需要的条目，不删除其他章已经写入的条目。
- 每一项都记在该章 README。

## 写完之后

- 核对过运行结果后，把 spec 状态改成 `示例已生成`。
- 在 spec 末尾「示例记录」填上每个场景的 `res://` 路径和日期。
- 不改无关章节的 spec 和场景。
- 在对话里按 `guide.md` 的顺序讲这一章，并给出运行命令。讲解留在仓库里，不把 `guide.md` 只写在聊天中。

## 例外

- 第 0 章不生成 `lessons/` 材料。读 `docs/specs/ch00-roadmap.spec.md` 即可。
- 第 19 章的材料是 `lessons/ch19-export/guide.md` 和 `README.md`，内容是导出步骤和结果。这一章可以没有玩法场景。导出目标按学员当前系统来，步骤里写明停在哪一步。

## 不要生成的东西

- 幻灯片、题库网站、和本章无关的第二套示例。
- 正式游戏里的玩法。学员没有点名改游戏本体时，改动留在该章 `lessons/`。
- 插件、存档框架、对象池、状态机框架。除非该章 spec 把它们列进了范围。
