# 术语

一句话够用。详细行为留到对应章节的示例里。

| 术语 | 含义 | 主要章节 |
| --- | --- | --- |
| 节点 | 引擎里的一个对象，带有类型和职责，例如显示图片或检测碰撞 | 第 2 章 |
| 场景 | 保存下来的一棵节点树，可以整棵拿去复用 | 第 2 章 |
| 场景树 | 游戏运行时所有节点的父子结构 | 第 2 章 |
| 实例化 | 把一个场景再生出一个节点，放进当前场景 | 第 2 章 |
| 资源 | 图片、声音、脚本、场景等可以保存和引用的数据 | 第 1、7 章 |
| 节点路径 | 从某个节点走向另一个节点的名字路径，例如 `$Sprite` | 第 4 章 |
| 信号 | 节点在事情发生时发出的通知，别的节点可以去听 | 第 5 章 |
| 动作 | 输入映射里的一个名字，用来代表「跳」「左移」而不是某个具体按键 | 第 6 章 |
| 碰撞层 / 遮罩 | 决定谁可以碰到谁的分组开关 | 第 10 章 |
| 瓦片 | 用来拼关卡的小图块 | 第 11 章 |
| 锚点 | 界面控件相对父控件边缘的吸附方式 | 第 13 章 |
| Autoload | 换场景后仍然存在的全局节点 | 第 15 章 |
| `res://` | 项目内部资源路径 | 第 17 章 |
| `user://` | 本机用户数据路径，存档放这里 | 第 17 章 |
