# 官方文档入口

本仓库按 Godot 4.7 学习。文档版本请选 4.7 或 stable，不要对照 3.x 手册写代码。

- 下载 4.7.2：<https://godotengine.org/download/archive/4.7.2-stable/>
- 手册首页：<https://docs.godotengine.org/en/4.7/>
- 你的第一个 2D 游戏（官方入门，可作对照，不代替本仓库章节）：<https://docs.godotengine.org/en/4.7/getting_started/first_2d_game/index.html>
- GDScript 基础：<https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/gdscript_basics.html>
- GDScript 风格指南：<https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/gdscript_styleguide.html>
- 2D 介绍：<https://docs.godotengine.org/en/4.7/tutorials/2d/index.html>

中文手册的更新常常慢于英文版。API 对不上时，以英文 4.7 文档为准，再用本仓库 `docs/standards/gdscript-style.md` 里的对照表改写旧教程。
