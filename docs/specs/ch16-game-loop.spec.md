## 学完应该能做什么

把移动、碰撞、界面和场景切换收成一局很小的游戏：有目标，有失败，能重开。

## 本章要认识的内容

- 一局游戏至少要有开始、进行中、胜利或失败、再来一次
- 分数或目标数量显示在界面上，数据变化通过信号或一处明确的持有者传递
- 失败后停住玩法并给出再来一次的入口
- 题材在学习这一章时再定。范围保持在一种操作、一种得分、一种失败

## 本章不展开

- 多关卡战役
- 存档（第 17 章）
- 手感打磨（第 18 章）
- 完整的敌人 AI。需要对手时，用一种会移动或会待在原地的简单对象即可

## 以后生成示例时要覆盖的点

- 能操作的角色，一种能得分或达成目标的接触
- 一种失败条件，失败后可以重开这一局
- 界面上能看见当前目标进度
- README 用十行以内说明这局的规则

## 自测

不改规则说明的前提下，能从开局玩到胜利或失败，并重新开始第二局。
