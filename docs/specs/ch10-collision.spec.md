## 学完应该能做什么

用碰撞层和遮罩控制谁碰到谁，并用 `Area2D` 做「进入范围就发生一件事」，和角色身体的碰撞区分开。

## 本章要认识的内容

- `CollisionShape2D`、`CollisionPolygon2D` 是形状，本身不等于会动的物体
- 碰撞层表示「我属于哪一类」，遮罩表示「我检测哪一类」
- `CharacterBody2D` 的阻挡，和 `Area2D` 的进入、离开
- `body_entered` 一类信号如何接到第 5 章的听法上
- `RayCast2D` 能问「这个方向上有没有东西」。知道用途即可，复杂查询留作以后的补充

## 本章不展开

- 导航和寻路
- 伤害公式、击退手感（第 16、18 章可以再用来做一局游戏）
- 物理关节

## 以后生成示例时要覆盖的点

- 角色会被地面挡住
- 一个 `Area2D` 区域，进入后有看得见或在输出里看得见的反应，离开后反应结束或再记一次
- README 画出或列出这一课用到的层和遮罩，说明谁检测谁

## 自测

能改一层或一个遮罩，让角色穿过原来会挡住它的物体，并说清改的是层还是遮罩。
