## 学完应该能做什么

从标题画面进入另一场景，再回到标题。知道 Autoload 在换场景之后仍然在，以及暂停时哪部分树会停。

## 本章要认识的内容

- 换场景会拆掉当前这棵树，再装上另一棵
- `change_scene_to_file` 或换成已经加载的打包场景，二者选一种作为本章主路径，另一种在 README 里点明
- Autoload：适合放「换场景也不能丢」的少量全局对象，例如分数入口或场景切换器
- 暂停：暂停后游戏树停住，界面仍可操作的概念

## 本章不展开

- 大型关卡管理和异步加载框架
- 把全部游戏规则都塞进一个 Autoload
- 存档格式（第 17 章）

## 以后生成示例时要覆盖的点

- 两个场景可以互相进入
- 一个 Autoload 上的数据在换场景后还能读到，用来看见「它还在」
- 暂停时，运动着的物体停住，界面上的继续操作仍然有效

## 自测

能说出哪一类数据适合放 Autoload，哪一类应该跟着场景一起消失。
