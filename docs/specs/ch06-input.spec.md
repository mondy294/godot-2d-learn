## 学完应该能做什么

在输入映射里定义动作，用动作而不是具体按键驱动一个看得见的响应，并知道键盘和手柄可以映射到同一个动作。

## 本章要认识的内容

- 输入映射、动作名、按键和手柄按键
- 按住、刚按下、刚松开这三种问法
- `Input.get_vector` 这一类「要一个方向」的读法
- `_unhandled_input` 和在 `_physics_process` 里查询动作，各自更适合什么场合（概念上分开即可）

## 本章不展开

- 跳跃手感、输入缓冲、土狼时间（第 18 章）
- 完整角色控制器（第 9 章）
- 可在菜单里改键（知道以后能做即可）

## 以后生成示例时要覆盖的点

- 项目或示例说明里有一组动作，例如左右和确认
- 按住方向时画面上的物体移动，点按确认时输出面板另有反应
- README 列出每个动作对应的默认按键，方便在编辑器里核对

## 自测

能新加一个动作并接到现有示例上，而不在代码里写死新的按键码。
