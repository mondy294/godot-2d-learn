## 学完应该能做什么

给角色或物体播一段看得见的动画，并在动画结束时收到通知。

## 本章要认识的内容

- `AnimatedSprite2D` 适合一连串帧图
- `AnimationPlayer` 适合按时间改位置、透明度、调用函数等多种轨道
- 动画库、动画名、播放和停止
- 动画结束可以变成信号，具体信号写法回顾第 5 章

## 本章不展开

- `AnimationTree` 和混合
- 骨骼
- 用动画轨道做完整战斗连招

## 以后生成示例时要覆盖的点

- 一个帧动画在循环播放
- 另一个短动画播放一次，结束后在输出面板或画面上留下「播完了」的痕迹
- README 说明两种节点各自为什么出现在这个示例里

## 自测

能说出「走路循环」和「开门播一次」更适合用哪种方式，以及播完之后该去听什么。
