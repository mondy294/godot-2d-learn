# 第 9 章：移动

- 状态：未开始
- 前置：第 4、6 章
- 示例目录：`lessons/ch09-movement/`

## 学完应该能做什么

用 `CharacterBody2D` 做左右移动、重力和落地，让角色在静态地面上走和跳。

## 本章要认识的内容

- `CharacterBody2D`、`velocity`、`move_and_slide`
- 重力加在物理帧里
- `is_on_floor` 这一类「现在贴着地面吗」的判断
- `StaticBody2D` 当作不会被推开的地面
- 顺带认识 `RigidBody2D` 和 `AnimatableBody2D` 的分工：谁适合被物理推着走，谁适合按动画移动的平台。这一章不要求把它们都做成玩法

## 本章不展开

- 碰撞层和遮罩的完整规则（第 10 章）
- 斜坡、移动平台、墙跳的手感细节（墙跳一类反馈放到第 18 章再考虑）
- 顶部视角和横版同时做完。示例先定一种视角，另一种只在 README 里说差在哪

## 以后生成示例时要覆盖的点

- 一个能左右移动的角色，掉下去会落在静态地面上
- 有一次跳跃或一次「离开地面再回来」的反馈，用来看见落地判断
- 速度用 `@export` 或常量，单位在注释里写明
