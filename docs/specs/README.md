# 章节规格

每一章一个 spec，用来圈定学习范围。状态初始都是 `未开始`。具体脚本留到学习该章时，按 [../standards/ai-coding.md](../standards/ai-coding.md) 生成到 `lessons/`。

新开一章时复制 [_template.spec.md](_template.spec.md)，文件名用 `chNN-短名.spec.md`。
