## 学完应该能做什么

让一个节点在事情发生时发信号，另一个节点去听，并说得出这种写法和互相直接调用的差别。

## 本章要认识的内容

- 引擎自带信号，例如按钮按下、区域进入
- 在编辑器里连接信号，以及在代码里连接信号
- 自定义信号和参数
- 信号适合「我发生了一件事，谁关心谁来听」

## 本章不展开

## 以后生成示例时要覆盖的点

- 两个独立节点：一个发出自定义信号，另一个收到后改变自己看得见的状态
- 一处用编辑器连接，或在 README 里明确说明为什么这一处改用代码连接
- 监听函数名字和信号名字能对上，注释写的是意图

## 自测

能给「玩家受伤时，界面血条要更新」指出谁发信号、谁监听，以及信号上适合带什么信息。
