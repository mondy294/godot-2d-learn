## 学完应该能做什么

做一个简单菜单和一个游戏内抬头显示，按钮能发出信号，窗口大小变化时控件仍然待在该待的位置。中文能在画面上正常显示。

## 本章要认识的内容

- `Control` 和 `CanvasLayer`：界面画在世界坐标之上
- 锚点、边距，以及容器（先认识横向、纵向、居中这几类）
- `Label`、`Button`、`TextureRect` 的用途
- 主题的概念：同一套字体和颜色可以复用。先会指定字体，不要求做完整个主题编辑器
- 引擎默认字体不含汉字。显示中文要把字体放进 `assets/fonts/` 并在控件上使用

## 本章不展开

- 复杂主题和皮肤系统的每一项
- 背包、对话树
- 可访问性和多语言框架。知道文本可以以后抽出来即可

## 以后生成示例时要覆盖的点

- 一个按钮，按下后切换一个看得见的界面状态，或发出信号让别的节点响应
- 一个显示数字的标签，脚本可以改这个数字
- 至少一处可见的中文，并在 README 写明字体文件从哪来、许可是什么

## 自测

把窗口拉大后，标题或按钮仍然停留在设计时希望的位置；画面上的汉字不再是方框。
