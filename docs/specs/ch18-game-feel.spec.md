# 第 18 章：手感与反馈

- 状态：未开始
- 前置：第 8、12、14、16 章
- 示例目录：`lessons/ch18-game-feel/`

## 学完应该能做什么

给已经能玩的一小局加上三类反馈：运动补间、粒子、声音或镜头上的短反馈。知道反馈是在事件发生时触发的。

## 本章要认识的内容

- `Tween` 适合在短时间里改变位置、缩放或透明度
- `GPUParticles2D` 或 `CPUParticles2D` 里先认识一种，用来做拾取、落地或受击的可见爆点
- 摄像机短暂偏移可以表达撞击。点到为止，不做成镜头语言课
- 这些反馈由第 5 章那种「事情发生了」的时机触发，并和第 14 章的音效放在同一时机

## 本章不展开

- 着色器和后期处理
- 高级粒子贴图制作
- 输入缓冲、土狼时间等平台跳跃专项。若示例题材用得上，只做其中一项，并在 README 标明这是额外手感

## 以后生成示例时要覆盖的点

- 一件事发生时，同时有可见变化和声音，或可见变化和镜头反馈
- 补间结束后物体处于可预期的状态，而不是停在半路
- 反馈脚本和玩法脚本分开，避免把全部代码堆进角色脚本

## 自测
