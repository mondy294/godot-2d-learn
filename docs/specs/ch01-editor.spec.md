# 第 1 章：编辑器与项目

- 状态：未开始
- 前置：第 0 章
- 示例目录：`lessons/ch01-editor/`

## 学完应该能做什么

用 Godot 4.7 打开本仓库，找到场景、文件系统、检查器、输出和调试器，运行主场景，并看懂报错出现在哪里。

## 本章要认识的内容

- 项目、场景、资源在编辑器里各自由哪个面板负责
- 运行整个项目，和只运行当前打开的场景，这两件事的差别
- 输出面板里的 `print`，以及断点停住脚本的大致用途
- 2D 窗口相关的项目设置：分辨率、拉伸模式
- 运行时的默认字体不含汉字，所以启动画面先用英文；中文界面留到第 13 章

## 本章不展开

- GDScript 语法细节
- 场景树怎么设计
- 玩法

## 以后生成示例时要覆盖的点

- 一个很短的场景，运行后在输出面板留下一行可辨认的中文
- README 里写明主场景路径，以及如何只运行当前场景

## 自测

能在文件系统里指出主场景，能让项目跑起来，能在输出里找到启动那一行字。
