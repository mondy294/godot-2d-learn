## 学完应该能做什么

在一件事情发生时播放音效，并让一段背景音乐持续播放。能把音效和音乐的音量分开考虑。

## 本章要认识的内容

- `AudioStreamPlayer` 不随位置变化，适合界面和背景音乐；`AudioStreamPlayer2D` 的音量跟画面位置有关，适合世界里的音效
- 播放、停止、循环
- 音频总线的概念：主总线、音乐、音效可以分成不同音量
- 音效适合由信号触发，回顾第 5 章

## 本章不展开

- 混音工程和效果器链
- 动态音乐分层
- 语音和字幕

## 以后生成示例时要覆盖的点

- 按下动作或进入区域时播放一次短音效
- 一段可以循环的背景声，和音效不抢同一个「唯一播放器」到互相打断，除非示例就是在演示打断
- README 写明音频文件放在该课目录还是 `assets/audio/`，以及音量在总线还是在播放器上调节

## 自测

把音效音量降到听不见时，背景声仍然在；或能指出该去改播放器还是改总线。
