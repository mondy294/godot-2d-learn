## 学完应该能做什么

把项目导出成 Windows 可运行程序，并知道编辑器缓存、导出产物和应当放进版本管理的文件有什么差别。

## 本章要认识的内容

- 导出预设、导出模板、主场景
- 导出前先让主场景或指定的示例场景能在编辑器里跑通
- 导出结果放到 `exports/` 或 `build/`，这两个目录不提交
- `.godot/` 是编辑器缓存，不提交。`project.godot`、场景、脚本和实际使用的资源要保留
- 缺模板、主场景为空、路径只在编辑器里有效，这几类常见导出失败的现象

## 本章不展开

- 应用商店上架
- Android、Web 的平台专项。本章以 Windows 为主，其它平台只列为以后可以加的预设
- 代码签名和安装包

## 以后生成示例时要覆盖的点

- 一份写给自己的导出步骤，放在 `lessons/ch19-export/README.md`
- 步骤里包含：安装导出模板、选择预设、确认主场景、输出到 `exports/`
- 若环境里已经装好 Godot，按步骤导出一次并记下结果；环境还不具备时，在 README 写明停在哪一步

## 自测

导出的程序能在不打开编辑器的情况下启动，并进入当时指定的主场景。
