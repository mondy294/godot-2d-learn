## 学完应该能做什么

用小图块拼出一块能站上去的地面，并让第 9 章那种角色在上面走动。

## 本章要认识的内容

- `TileSet` 描述图块，`TileMapLayer` 把图块铺到关卡里
- 图块来源可以是一张切好的图集
- 给图块加碰撞，让它变成地面而不是纯装饰
- 多层的概念：地面一层、装饰一层。这一章先分清用途，不追求美术

## 本章不展开

- 程序化生成大地图
- 地形自动拼接的每一种规则都做一遍。能做出一种可走的地面即可
- 导航区域

## 以后生成示例时要覆盖的点

- 一层可以站立的瓦片地面
- 角色或一个会下落的物体确实落在瓦片上，而不是落在单独摆的静态矩形上
- README 写明图块资源放在该课目录还是 `assets/tilesets/`

## 自测

能再画或再铺几格地面，运行后角色仍然落在新铺的格子上。
