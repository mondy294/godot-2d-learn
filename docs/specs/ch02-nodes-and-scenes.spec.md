# 第 2 章：节点与场景

- 状态：未开始
- 前置：第 1 章

## 学完应该能做什么

说出常见 2D 节点各自站在树里的哪个角色，能把一棵节点树存成场景，再把这个场景实例化到另一棵树里。

## 本章要认识的内容

- 节点、父子关系，以及子节点会跟着父节点移动
- `Node`、`Node2D`、`Sprite2D`、`Camera2D`、`CanvasLayer`、`Control` 各自的大致用途，这一章只建立地图，不逐个做完
- 场景是保存下来的节点树，实例是这棵树的一次使用
- 把角色、道具做成单独场景再拖进关卡

## 本章不展开

- 脚本怎么引用节点（第 4 章）
- 信号（第 5 章）
- 碰撞形状和物理（第 9、10 章）
- 瓦片地图（第 11 章）

## 以后生成示例时要覆盖的点

- 一个「道具」场景，被主示例场景实例化两次，改其中一个父节点的位置时两个实例的相对关系仍能看出来
- 场景树里能指出根节点、子节点和实例化进来的节点

## 自测

给定「玩家、地面、一扇门」，能说明它们适合做几个场景，以及谁当谁的父节点。
