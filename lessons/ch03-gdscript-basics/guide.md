# 第 3 章：GDScript 基础

## 这一章解决什么问题

前面两章的脚本只会在场景就绪后打印一行字。这一章认识 GDScript 里用来计算的那一部分：带类型的数据、函数、条件、循环、数组和字典。运行后，结果出现在终端里，画面上仍然只有一行英文。

## 先看哪棵场景树

场景是 `scenes/basics.tscn`。没有从别的场景实例化进来的节点。

- `Basics`：根节点，挂着 `scripts/basics.gd`
- `UI/Title`：屏幕中央的英文 `Chapter 3`

## 代码在做什么

看 `scripts/basics.gd`。第一行 `extends Node2D` 表示这份脚本挂在 `Node2D` 上。继承的细节先不用管。

`_ready` 把几种计算结果依次打印。函数负责算出这些值：

- `add_score` 把两个整数相加。`14` 加上 `1.5` 取整后的 `1`，得到整数 `15`
- `rank_for` 用 `if` 看分数有没有达到常量 `PASS_SCORE`。达到就返回枚举 `Rank.PASS`
- `rank_name` 把枚举变成终端里的 `pass` 或 `retry`
- `find_amount` 在字典里查物品数量。`coin` 查到 `2`，`potion` 不在表里，返回 `null`
- `steps` 是数组。`for` 把 `1`、`2`、`3` 加总，得到 `6`

`Vector2(12, 8)` 是一个坐标，这一章只把它打印出来，不拿它去移动节点。

## 建议改一处

把常量 `PASS_SCORE` 从 `10` 改成 `20`，保存后再运行。分数仍是 `15`，所以下面两行会变成：

```
第 3 章：整数 15，小数 1.5，是否通过 false。
第 3 章：评价 retry，坐标 (12.0, 8.0)。
```

其余三行不变。

## 自测

再改一个数字或一个条件，先写下终端里会变的那一行，再运行对照。对得上，这一章就通过了。
