# 第 6 章示例

对应规格：`docs/specs/ch06-input.spec.md`

## 场景

| 场景 | 关注点 |
| --- | --- |
| `scenes/move.tscn` | 按住方向移动方块，按下确认时在终端打印一行 |

必须的节点：根节点 `Move`，子节点 `Token`。

本章往 `project.godot` 的 `[input]` 追加了动作，没有改主场景。

## 动作和默认按键

在编辑器里打开项目设置的输入映射，可以核对这些名字。键盘和手柄都接到同一个动作上。

| 动作 | 键盘 | 手柄 |
| --- | --- | --- |
| `ch06_left` | A，左方向键 | 左摇杆向左 |
| `ch06_right` | D，右方向键 | 左摇杆向右 |
| `ch06_up` | W，上方向键 | 左摇杆向上 |
| `ch06_down` | S，下方向键 | 左摇杆向下 |
| `ch06_accept` | 空格 | 手柄的南键（Xbox 的 A） |

## 运行

在仓库根目录执行：

```
godot --path . res://lessons/ch06-input/scenes/move.tscn
```

窗口上方是 `Chapter 6`，中央有一个青色方块。

- 按住 `A` `D` `W` `S` 或方向键，方块朝对应方向移动
- 按下空格的那一下，终端出现：

```
第 6 章：确认动作被按下。
```

按住空格不松手，这行不会因为按键重复而连着刷出来。无界面运行看不出方块移动，这一课需要窗口和键盘。

在编辑器中打开 `scenes/move.tscn` 后运行当前场景（F6），和上面的命令是同一件事。不要把这一课写成项目主场景。
